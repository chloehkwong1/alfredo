- **How do I add a repo?** Sidebar footer → "Add repo" (or ⌘⇧R).
- **How do I create a worktree?** Sidebar → **+** button or ⌘N.
- **How do I switch from Claude to Codex or Gemini?** Global Settings
  → Agents → Default Agent. Only detected providers show up.
- **How do I run two agents on the same worktree?** Use the **+** in
  that worktree's tab bar to open a second agent tab alongside.
- **How do I mark a worktree as blocked / in progress / done?** Drag
  it in the sidebar onto the target kanban column. No right-click
  menu — the drag is the mechanism.
- **Where are Alfredo's settings stored?** In a global `app.json` per
  user. Repo-level settings live in Repository Settings.
- **How do I delete a worktree?** Right-click → Delete. Auto-delete
  is opt-in under Repository Settings → Archive & Cleanup.
- **What's the difference between archiving and deleting?** Archive
  hides the worktree but keeps it on disk; delete is permanent.
- **Does Alfredo support Windows?** No — macOS and Linux only.
- **Where do I report a bug?**
  https://github.com/chloehkwong1/alfredo/issues.
