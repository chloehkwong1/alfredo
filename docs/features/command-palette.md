title: The command palette
keywords: [launcher, quick actions, search commands, cmdk]
ui_path: Press ⌘⇧P anywhere in the app
---

Press ⌘⇧P from anywhere in Alfredo to open the command palette, a fuzzy-
searchable launcher for the actions you'd otherwise hunt through menus
and shortcuts for. Start typing and the list filters as you go (powered
by cmdk), so "sett" jumps to Go to Settings and "term" narrows to the
terminal-related entries. The five most-recently-run commands surface at
the top when the search box is empty, so repeat actions stay one keypress
away.

Commands are grouped into Actions, Navigation, Worktrees and Pull
Request. From Actions you can create a new worktree, open a Claude or
terminal tab, split the active pane, toggle the sidebar or changes
panel, copy the branch name / PR URL / worktree path, and open the
worktree in your editor, terminal or Finder. Navigation jumps to
settings, the keyboard shortcut overlay, or — in multi-repo setups —
switches repos. Worktrees lists every non-archived worktree for instant
switching, and Pull Request shows options like View PR on GitHub, Rerun
failed checks, and Fix failing checks with agent when the active
worktree has a PR.
